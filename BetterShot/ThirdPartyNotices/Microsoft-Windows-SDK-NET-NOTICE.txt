These files are supplied by the .NET SDK when an app targets a Windows 10 SDK version (BetterShot targets
net10.0-windows10.0.19041.0) and let BetterShot call Windows Runtime APIs used for screen recording
(Windows.Graphics.Capture, Windows.Media.Transcoding, Windows.Media.Capture).
